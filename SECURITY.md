# Security Policy

## Supported Versions

Security fixes are made on the `main` branch. If you found an issue on an
older commit, include that commit in your report.

## Reporting a Vulnerability

Submit a [private vulnerability report](https://github.com/hodovani/workbench/security/advisories/new)
on GitHub. Please keep vulnerability details out of public issues and pull
requests.

Include the affected feature or URL, the commit if known, steps to reproduce
the issue, and its potential impact. Remove credentials and personal data
from any logs or screenshots.

Reports are reviewed as time permits. Follow-up happens in the private
GitHub report. If the issue is confirmed, the maintainer will coordinate
any fix and public disclosure there. If the report is closed without a fix,
the maintainer will explain the reason.
